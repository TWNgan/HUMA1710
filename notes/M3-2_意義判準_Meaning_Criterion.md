## 0. 一頁總覽 ⭐⭐⭐

```
語句 (sentence)
 ├─ 有真值 (truth-value) → 述句 (statement) → 有認知意義 (cognitive meaning)
 │    ├─ 分析述句 (analytic)：單從語句分析判定真假
 │    │     ├─ 恆真句 tautology（必真）
 │    │     ├─ 矛盾句 contradiction（必假）
 │    │     └─ 透過語義界定判定（王老五是未婚漢 ✔；神奇女俠是男性 ✘）
 │    └─ 綜合述句 (synthetic)：要經驗事實判定真假
 │          ├─ 綜合真句 (synthetic truth)：地球上有生命；HUMA 1710 is a H-CC
 │          └─ 綜合假句 (synthetic falsity)：地球是平的；HUMA 1710 is a A-CC
 │          └─ 用 4 個驗證原則判斷綜合語句有冇認知意義
 └─ 冇真值 → 冇認知意義（但可以有「非知意義」）
```

**四個驗證原則（只用於綜合語句）**
| | 「**證明**」（嚴） | 「**支持**」（寬） |
|---|---|---|
| **為真** | **檢證原則 Verification**（原則上可能由經驗方法**證明為真**） | **印證原則 Confirmation**（原則上可能被經驗證據**支持為真**）→ 處理**非封閉集合的全稱語句** |
| **為假** | **否證原則 Falsification**（原則上可能由經驗方法**證明為假**）→ 處理**非封閉集合的全稱語句**；**區分科學與偽科學** | **非證原則 Disconfirmation**（原則上可能被經驗證據**支持為假**）→ 處理**特稱語句**；常見於**品質保證** |

- 印證 = 檢證嘅**較寬鬆形式**；非證 = 否證嘅**較寬鬆形式**。

## 1. 開場
- 《莊子・齊物論》：「**故知止其所不知，至矣。**」（知道停喺自己唔知嘅地方，就係最高嘅智慧 → 意義判準劃清可討論/不可討論嘅界線）

## 2. 認知意義 Cognitive Meaning ⭐⭐⭐
- **意義判準有助我們分辨那些語句 (sentence) 才是具有真值 (truth-value) 的述句 (statement)。**
- **真值包括真 (truth) 和假 (falsity) 兩個值。**
- 例：
  | 語句 | 有冇真值？ |
  |---|---|
  | 香港科技大學位處香港西貢區 | ✔（真） |
  | 史維是香港科技大學現任校長 | ✔（有真假可言） |
  | 史維是香港科技大學校長 | ✔（有真假，但**時間闕義**：幾時？） |
  | 史維是香港科技大學前任校長**嗎？** | ✗ **問句**冇真值 → 唔係述句 |
- ⭐ **在意義判準之下，語句至少要談得上真假，它才有認知意義。**
- ⚠️ 有認知意義 ≠ 真；**假嘅語句都有認知意義**（例「地球是平的」有認知意義，只係假）。

## 3. 析合區分 Analytic and Synthetic Distinction ⭐⭐⭐
- **如果不能透過語句分析或經驗方法檢測語句的真假，它就沒有認知意義。**
- **所有述句可歸類為：分析述句 (analytic statement)、綜合述句 (synthetic statement)。**

### 3.1 分析述句 Analytic statement ⭐⭐
**單從語句分析就足以判定真假**，包括：
| 類型 | 例子 | 真假 |
|---|---|---|
| 具有**恆真句 (tautology)** 形式的語句 | **外面有下雨或沒有下雨**；**他是年輕人則他不可能同是老人** | 必真 |
| 具有**矛盾句 (contradiction)** 形式的語句 | **外面有下雨同時沒有下雨**；**他是年輕人同時也是老人** | 必假 |
| **透過語義界定**便可判定語句真假 | **王老五是未婚漢**（真）；**神奇女俠是男性**（假） | 由定義決定 |

⚠️ 分析述句**可以係假**（矛盾句、「神奇女俠是男性」）——分析 ≠ 必真！

### 3.2 綜合述句 Synthetic statement ⭐⭐
**原則上不能單從語句分析，而需要以經驗事實去分辨真假**，包括：
| 類型 | 例子 |
|---|---|
| **綜合真句 (synthetic truth)** | **地球上有生命**；**HUMA 1710 is a H-CC**（Humanities Common Core） |
| **綜合假句 (synthetic falsity)** | **地球是平的**；**HUMA 1710 is a A-CC**（Arts Common Core） |

### 3.3 析合區分的三個特質 ⭐⭐⭐
| | **分析述句** | **綜合述句** |
|---|---|---|
| 模態 | **必然 (necessary)** | **適然 (contingent)** |
| 知識來源 | **先驗 (a priori)**（唔使經驗） | **後驗 (a posteriori)**（要靠經驗） |
| 信息 | **沒有信息內容**（唔講世界嘅事） | **有信息內容** |

- 呼應：言辭空廢 = 用「**冇信息內容**」嘅重言句（分析述句）**冒充**「**有信息內容**」嘅事實陳述（綜合述句）。

## 4. 四個驗證原則 ⭐⭐⭐
> **四個原則都是為了判斷「綜合語句」是否具有認知意義。**（⚠️ 唔係用嚟判斷分析語句；亦唔係判斷語句**真定假**，而係判斷**有冇認知意義**）

### 4.1 檢證原則 Verification Principle
- 一個綜合語句 S：**如果 S 在原則上，有可能由經驗方法被證明為真**，則 S 就有認知意義；**如果 S 在原則上，沒有可能由經驗方法被證明為真**，則 S 就沒有認知意義。
- 例：
  - 「**有一隻天鵝是白色的。**」（搵到一隻就證明為真）
  - 「**有一個同學在 HUMA 1710 Mid-term 拿到滿分。**」
  - 「**Dr. Nam 2026 年 9 月 4 日上午在 2407 室上課。**」
- ⚠️ 適合**特稱語句**（「有一個…」）同**具體單稱語句**。

### 4.2 印證原則 Confirmation Principle
- 一個綜合語句 S：**如果 S 在原則上，有可能被經驗證據支持為真**，則 S 就有認知意義；**否則**冇。
- ⭐ **印證原則是檢證原則的一種較寬鬆的形式**，以幫助判斷「**非封閉集合的全稱語句**」是否有認知意義：
  - 「**所有天鵝都是白色的。**」
  - 「**所有科大學生都是男生。**」
  - 「**所有人類女性都有一對相同的性染色體 (XX)。**」
- 點解要放寬？「所有天鵝」係**非封閉集合**（過去、現在、未來所有天鵝，冇辦法逐一檢查）→ **原則上冇可能「證明」為真** → 用檢證原則會被判冇認知意義（太嚴）；但可以**被證據支持**（見到越多白天鵝越支持）→ 用印證原則就有認知意義。

### 4.3 檢證／印證原則的應用 ⭐
- **分辨語句／理論是否有認知意義**；
- ⭐ **就分析哲學而言，一個語句若果談不上真假，則連假的都不如**，例如：
  - 將**鬼神**定義為**超驗**的學說；
  - 將**玄學**視為一種**無形力量**的學說；
  - 將**靈魂、死後世界**定義為**經驗世界以外**的研究。
  - （= 李天命「連假語句的資格都沒有」：柏烈得萊「絕對」）

### 4.4 否證原則 Falsification Principle
- 一個綜合語句 S：**如果 S 在原則上，有可能由經驗方法被證明為假**，則 S 就有認知意義；**否則**冇。
- 跟印證原則一樣，能判斷「**非封閉集合的全稱語句**」是否有認知意義：
  - 「所有天鵝都是白色的」→ 搵到**一隻黑天鵝**就證明為假 → 有認知意義。
  - 「所有科大學生都是男生」→ 一個女生就否證。
  - 「所有人類女性都有一對相同的性染色體 (XX)」→ 一個反例就否證。
- 邏輯：全稱語句**唔能完全證實**，但**可以被一個反例證偽**（不對稱性）。

### 4.5 非證原則 Disconfirmation Principle
- 一個綜合語句 S：**如果 S 在原則上，有可能被經驗證據支持為假**，則 S 就有認知意義；**否則**冇。
- ⭐ **否證原則的一種較寬鬆的形式**，以幫助判斷「**特稱語句**」是否有認知意義，例如：
  - 「**有一隻天鵝是黑色的。**」
  - 「**有一個人類男性擁有一對相同的性染色體 (XX)。**」
  - 「**有一個科大僱員月薪超過二十萬。**」
- 點解要放寬？特稱語句（「有一隻…」）**原則上冇可能「證明為假」**（要檢查晒所有天鵝先講到「冇一隻係黑」）；但可以**被證據支持為假**（搵極都搵唔到）。

### 4.6 否證／非證原則的應用 ⭐⭐
- 跟前述兩個原則一樣用以**判斷語句是否有認知意義**。
- ⭐ **否證原則亦用於區分科學與非（偽）科學 (science vs pseudo-science)**（**波柏 Karl Popper** 嘅 demarcation）：
  - 「**人是理性的**」
  - **孟子性善論**
  - **S. Freud's psychoanalytic theory**（佛洛依德精神分析）
  - **K. Marx's theory of history**（馬克思歷史理論）
  - → 呢啲理論**任何情況都可以解釋**，**冇可能被否證** → 唔係科學（偽科學）。（= 油腔滑調／封閉系統）
- ⭐ **非證原則常見於日常生活中的品質保證 (quality assurance)**：「**有一件產品不合符標格。**」（抽樣檢查搵唔到 → 支持「冇不合格產品」）

### 4.7 四原則配對表（必背）⭐⭐⭐
| 原則 | 方向 | 強度 | 主要處理 | 例子 |
|---|---|---|---|---|
| **檢證 Verification** | 證明**為真** | 嚴（證明） | 特稱／單稱語句 | 有一隻天鵝是白色的 |
| **印證 Confirmation** | 支持**為真** | 寬（支持） | **非封閉集合的全稱語句** | 所有天鵝都是白色的 |
| **否證 Falsification** | 證明**為假** | 嚴（證明） | **非封閉集合的全稱語句**；**科學 vs 偽科學** | 所有天鵝都是白色的 |
| **非證 Disconfirmation** | 支持**為假** | 寬（支持） | **特稱語句**；**品質保證** | 有一隻天鵝是黑色的 |

記憶法：「**檢印**」向**真**，「**否非**」向**假**；「**檢否**」要**證明**（嚴），「**印非**」只要**支持**（寬）。
全稱語句 → 印證（真方向放寬）／否證（假方向本身就得）；特稱語句 → 檢證（真方向本身就得）／非證（假方向放寬）。

## 5. 非知意義 Non-cognitive Meaning ⭐⭐⭐
- ⭐ **沒有認知意義不一定等於完全沒有意義/價值。**
- 沒有認知意義的語句可能具有以下的**非知意義**：
  | 非知意義 | 例子 |
  |---|---|
  | **規範意義 (normative)** | **孟子性善論** |
  | **情感意義 (emotive)** | 「**煮豆燃豆萁，豆在釜中泣，本是同根生，相煎何太急。**」（曹植《七步詩》） |
  | **評價意義 (evaluative)** | 「**萬般皆下品，惟有讀書高。**」 |
  | **美學意義 (aesthetic)** | 「**天街小雨潤如酥，草色遙看近卻無。**」（韓愈） |
- ⚠️ 孟子性善論：**冇認知意義**（否證原則下唔可否證）**但有規範意義**。

## 5½. 課堂補充：講者點講（以此為準）⭐⭐⭐

- ⭐ **意義判準係上半個 course 嘅重點**（期中前最後一個 topic）。
- ⭐ **分析述句嘅核心只有恆真句、矛盾句**；「透過語義界定」係為日常語言而放寬，爭議較大。講者話 slides 嘅「**他是年輕人則他不可能同是老人**」「他是年輕人同時也是老人」其實要靠**語義**（年輕 vs 老）先判斷到，唔係純句式；純句式版本係「他是年輕人則他**不可能同時不是**年輕人」（A 或非 A）。⚠️ 「重言句」係咪等於「恆真句」：唔同書講法唔同——如果考，講者會加 remark。
- ⭐ **必然 = 機率 1（或 0）**；**適然 = 0 同 1 之間**（可以變嘅就係適然）——機率再高（地球上有生命）都**唔係必然**。三個分辨方法之中，講者認為**必然／適然最實在**。
- ⭐ **冇信息內容 ≠ 冇意義**：必然真／必然假都有真假可言 → **有認知意義**。言辭空廢要求**必然真**嘅答案；矛盾句冇信息內容但唔係空廢。
- ⭐ 判斷真假：**先試語句分析，唔得先用經驗事實**（概念 → 事實 → 評價）。
- ⭐ 神秘經驗、極個人經驗、幻聽**唔算經驗方法**。分析哲學唔係一開始就禁止講鬼神、靈魂——睇你點界定：定義為**超驗** → 冇認知意義。
- ⭐⭐ **證明 vs 支持**：證明 = 搵到**所有**證據（100%）；支持 = 有經驗證據支持；分析哲學家：支持只要**大過零**就得（實際要幾多睇學科，例如 p-value 0.05）。
- ⭐⭐ **檢證嚴、印證鬆；否證嚴、非證鬆**。推論：**通過檢證 ⇒ 必然通過印證**；**證明為假 ⇒ 當然可以支持為假**。
- ⭐⭐ **科學 = 有認知意義 + 多一層要求：接受被否證（黑天鵝）**——科學兩個面向：可以被**印證**（支持為真）＋ **接受可以被經驗方法證明為假**。經濟、finance、歷史都講證據（有認知意義），分別在於接唔接受自己會錯。睇嘅唔係學科題材，而係**佢點樣講佢嘅論斷**。
- ⭐⭐ 分析哲學家傳統上「打」三個：**「人是理性的」**（西方哲學傳統）、**Freud**（性衝動解釋一切行為）、**Marx**（歷史必然走向共產——「未到而已」）。**要必然性 ⇒ 只能係分析述句 ⇒ 先於經驗、唔受反例推翻 ⇒ 冇信息內容**（＝李天命：冇語句可以既有實質內容又有必然性）。講者個人睇法：孟子性善論係「分析地講」。
- ⭐ 例：「**股價低時買入、高時賣出，扣除手續費，正數就一定賺錢**」＝**分析述句式**表達（冇參考價值）；**backtest**（用過去數據推將來）＝**綜合**，絕對唔係必然真。
- ⭐ **非證原則 → QA**：產品抽驗幾件冇事就出廠；快測 disclaimer。
- ⭐⭐ 分析哲學將人類知識分三部分：**分析性**（數學、邏輯）／**經驗性（綜合）**／**非知意義**（規範、情感、評價、美學）——「**不是 no meaning**」，分析哲學「留了個位」，只係話佢哋冇認知意義、學術資源應放喺有認知意義嘅嘢。作弊例：**捉唔捉到你 = 經驗事實**（有認知意義）；**應唔應該懲罰 = 規範**（分析哲學家唔處理）。
- ⭐ 講者 T/F 示範：「**一個理論冇認知意義，係咪代表冇意義？**」→ **False**。
