# M2-2b 語言的陷阱（講者 slides）The Pitfalls of Language

> 來源：Module 2 Readings「2b. The Pitfalls of Language」（講者 slides，22 頁）
> ⚠️ 呢份係**講者自己嘅分類**（4 種），同李天命 2.2 嘅 6 種唔同 → **兩套都要識**，考試好可能用呢套 + 謬誤名稱（英文）。
> ⭐ = 極高機會考

## 0. 一句總結 ⭐⭐⭐

**語言的陷阱（講者版）4 種：**
1. **歧義 Ambiguity** → 謬誤：**模稜兩可 (Equivocation)**、**歧義句構 (Amphiboly)**
2. **含混 Vagueness** → 謬誤：**連續體謬誤 (Continuum Fallacy)**、**滑坡謬誤 (Slippery Slope Fallacy)**
3. **著色字詞 Coloured Word** → 謬誤：**訴諸憐憫 (Appeal to Pity)** ⊂ **訴諸情感 (Appeal to Emotion)**
4. **言辭空廢 Empty Verbalism** → **絕對空廢 / 相對空廢**

| 陷阱 | 對應謬誤（英文要識） |
|---|---|
| 字詞歧義 | **The Fallacy of Equivocation（模稜兩可的謬誤）** |
| 語句歧義 | **The Fallacy of Amphiboly（歧義句構的謬誤）** |
| 含混 | **Continuum Fallacy（連續體謬誤）**；**Slippery Slope Fallacy（滑坡謬誤）** |
| 著色字詞 | **Fallacy of Appeal to Pity（訴諸憐憫）**，係 **Fallacy of Appeal to Emotion（訴諸情感）** 嘅子類 |
| 言辭空廢 | **Tautological proposition（重言命題）冒充 factual statement（事實陳述）** |

### 李天命 6 陷阱 vs 講者 4 陷阱（對照）
| 李天命《語理分析的思考方法》 | 講者 slides |
|---|---|
| 闕義、歧義、含混、著色、實化、僻義 | 歧義、含混、著色字詞、**言辭空廢** |
| 空洞派／油腔滑調（2.1）、「真但多餘」（僻義） | ≈ **言辭空廢 (Empty Verbalism)** |

## 1. 開場 & 語言與思考（slide 1–2）

- 《孟子・盡心下》：「口之於味也，目之於色也，耳之於聲也，鼻之於臭也，四肢之於安佚也，**性也，有命焉，君子不謂性也**。仁之於父子也，義之於君臣也，禮之於賓主也，智之於賢者也，聖人之於天道也，**命也，有性焉，君子不謂命也**。」（「性」「命」喺唔同脈絡有唔同意思 → 引入歧義）
- **語言與思考**：在運用語言的同時，我們應對這種幫助我們**表達意見、描述外物的工具**進行**檢查**，從而避免某些使用語辭的方式**誤導、混淆或妨害了思想的正常運作**。
- **日常語言 vs. 人工語言** ⭐：
  - 「**九龍及新界部分地區落雨**」→ 日常語言有歧義：「部分」只修飾新界？定九龍同新界都係部分？
  - 人工語言（符號邏輯）可以清楚分開兩個解讀：
    - `(x)(Kx ⊃ Rx) · (∃x)(Nx ⊃ Rx)` → **九龍全部地區** + 新界部分地區落雨（`(x)` = 全稱量詞 all）
    - `(∃x)(Kx ⊃ Rx) · (∃x)(Nx ⊃ Rx)` → **九龍部分地區** + 新界部分地區落雨（`(∃x)` = 存在量詞 some）
  - 重點：**人工語言精確無歧義**；日常語言方便但易有陷阱（但語理分析**不採用人工語言**，係喺日常語言中運用邏輯思考）。

## 2. 歧義 Ambiguity ⭐⭐⭐

**定義：具有多過一個意義的字詞或詞句。**

### 2.1 兩種歧義
| 類型 | 例子（slide） | 解釋 |
|---|---|---|
| **1. 字詞歧義 (lexical ambiguity)** | **欠**、**發夢**、**掛號** | 欠：欠債 (owe) / 欠缺 (lack) / 打呵欠；發夢：瞓覺做夢 / 不切實際嘅幻想；掛號：掛號信 / 醫院登記掛號 |
| **2. 語句歧義 (structural / syntactic ambiguity)** | **路不通行不得在此小便**、**求學不是求分數**、**練跑減慢性病風險** | 「路不通行，不得在此小便」vs「路不通，行不得，在此小便」；「練跑減**慢性病**風險」vs「練跑**減慢性病**風險」 |
| 新聞標題（slide 4 圖） | 「**美無人機空襲巴西北部炸死至少8人**」 | 「**巴西**／北部」(Brazil) vs「**巴**（基斯坦）／**西北部**」(Pakistan) |

### 2.2 歧義嘅好處（歧義不一定有問題，也可以說是必需）⭐⭐
1. **字詞多義可免除增加新字詞的麻煩**（= 李天命「語言的經濟」）
2. **語言避諱**（避開直接講忌諱嘅嘢）
3. **創作**（諧音雙關）：
   - 「**因荷而得藕，有杏不須梅。**」→ 荷 = **何**、藕 = **偶**、杏 = **幸**、梅 = **媒** →「因何而得偶，有幸不須媒」
   - 「**東邊日出西邊雨，道是無晴卻有晴。**」→ 晴 = **情**（劉禹錫《竹枝詞》）
   - 「**二、三、四、五；六、七、八、九；南北。**」→ 缺「**一**」(衣) 少「**十**」(食)；有南北冇「**東西**」→ **缺衣少食，沒有東西**
4. **避重就輕**（留後路，兩面都講得通）：
   - 「**下雨天留客天留我不留**」→「下雨天，留客天，留我不？留！」vs「下雨天留客，天留，我不留。」
   - 「**人多病少財富**」→「人多，病少，財富」vs「人多病，少財富」
   - 「**誰都看不上**」→「（佢）睇唔起任何人」vs「冇人睇得上（佢）」

### 2.3 歧義嘅壞處 → 歧義性謬誤 ⭐⭐⭐
**壞處：不能分辨歧義語辭每次出現時所代表的意義，輕則成為笑話，重則會混淆思想。**

| 歧義類型 | → 謬誤 |
|---|---|
| **字詞歧義** | → **模稜兩可的謬誤 (The Fallacy of Equivocation)** |
| **語句歧義** | → **歧義句構的謬誤 (The Fallacy of Amphiboly)** |

**① 模稜兩可的謬誤 The Fallacy of Equivocation**（同一個**字詞**喺論證中途轉咗意思）
| 例子 | 邊個字轉咗意思？ |
|---|---|
| 「**我們不能踏進同一條河兩次。**」 | 「**同一條河**」：同一條河（身份）vs 同一批河水 |
| 「**爭取自由最終都是徒勞無功的，因為人生總會受到約束。**」 | 「**自由**」：政治/社會自由 vs 完全唔受任何約束嘅絕對自由 |
| 「**有室友勝過沒有任何東西；沒有任何東西勝過有個女/男朋友。因此，有室友勝過有個女/男朋友。**」 | 「**沒有任何東西**」：一無所有 (having nothing) vs 冇一樣嘢（比佢好）(nothing is better) |

**② 歧義句構的謬誤 The Fallacy of Amphiboly**（**句子結構**可以有兩種讀法）
- 「**我們不應該支持他，他是反對美國的單邊主義提倡者。**」→「反對【美國的單邊主義】的提倡者」vs「【反對美國】的單邊主義提倡者」
- 新聞標題（slide 10 圖）：
  - 「**兒子生性病母倍感安慰**」→「兒子**生性**，**病母**倍感安慰」vs「兒子**生性病**，母倍感安慰」
  - 「**挪威農民餓死逾400隻豬判囚1年**」→ 農民**餓死**咗？定農民**令 400 隻豬餓死**？
  - 「**父涉姦兒子女友被捕**」→ 父涉姦**兒子**？定父涉姦**兒子女友**？
  - 「**新公屋廁廚加大便利輪椅戶**」→「廁廚**加大**，**便利**輪椅戶」vs「廁廚加**大便**……」

## 3. 含混 Vagueness ⭐⭐⭐

**定義：當一個語辭的應用範圍沒有截然明確的界線，它就是含混的語辭。**
- 例子：**高矮、貧富、冷暖**；**成功、快樂、色情**；**重要、信心、尊重**

### 3.1 含混嘅功能／好壞
- **語言中不能或缺的**：例如「**大聲啲**」、「**講快啲**」
- **好處**：可幫助我們**約略地描述當前狀況**，具有一定**彈性**。
- **短處**：例如在**制定法例**時，我們必須釐訂**清晰而明確**的內容，在這些情況下就**必須避免字詞的歧義與含混**。
- **壞處**：它的**彈性**或會被人利用來製造**空話／大話**（語言的自覺篩選），從而**誤導思想**。

### 3.2 連續體謬誤 Continuum Fallacy ⭐⭐
- **利用語詞的含混性質，誤導人將能約略區分的事物視為不能區分。**
- 例：「**有錢人和窮人沒有大分別**」；「**我和拿 A- 的室友差不多**」
- 破解（李天命）：**「X 沒有分明的界線」並不涵蘊「X 沒有約略的界線」**。（又叫 Fallacy of the Beard / 連鎖論證）

### 3.3 滑坡謬誤 Slippery Slope Fallacy ⭐⭐
- **推論過程表現為一種環環相扣的因果關係，但每一環節中的因果關係卻只是「可能」而非「必然」。**
- 例：
  - 「**我們若同意主動安樂死，進一步就會接受被動安樂死，最後只會走草菅人命的結果。**」
  - 「**大學生不應該上莊，上莊就會沒有時間學習，也沒有時間做實習，最後就會因成績不好，沒有工作經驗，而找不到工作。**」
- ⚠️ 關鍵字：每一步只係「**可能**」(possible)，唔係「**必然**」(necessary)。

**⚠️ Continuum vs Slippery Slope 分辨**
| | Continuum Fallacy | Slippery Slope Fallacy |
|---|---|---|
| 結論 | 「**冇分別**／分唔到」 | 「**最終會導致嚴重後果**」 |
| 手法 | 利用**含混**、漸變冇界線 | **一連串因果鏈**，每步只係可能 |

## 4. 著色字詞 Coloured Word ⭐⭐⭐

- **著色字詞不但能表露和發洩說話者的感受，亦能引起其他聽者的情感反應。**
  - 例：**堅定／固執**；**公僕／公務員**
- ⭐ **著色字詞的情緒意義或會隨時間而改變**：例「**鬼佬**」
- ⭐ **不同情感下形容相同的狀況可能用上不同的字眼**：
  - **參考／抄襲**
  - **冷血殺人／英勇殺敵**
  - **只剩／還有**（「只剩一半」vs「還有一半」）
- **好處**：**有利於自身心理平衡，並帶動別人情緒**，常見於**文學作品**之中。
- **壞處**：**影響冷靜和客觀的思考或討論**。當人們**企圖利用著色字詞去誘使別人接受自己的論點，而不是藉著經驗証據或邏輯推論去說服別人時**。
  - 例：**廣告：「唔買就笨」**；**政治宣傳**（slide 圖：「KEEP CALM AND CARRY ON」海報）

### 4.1 訴諸憐憫 Fallacy of Appeal to Pity ⭐⭐
- **訴諸憐憫是訴諸情感 (Fallacy of Appeal to Emotion) 的一個子類。**
- **訴諸情感**：話者**不以證據**，而是**利用情緒用語或其他手段，博取同情或煽動情緒**。
- 例：
  - 有個年青人被控**用斧頭殺害雙親**，鐵證如山、無可抵賴，佢向法官求情，理由係：**佢係個孤兒**。（孤兒正正係佢自己造成！）
  - 有個學生**考試作弊導致不合格**，向老師求情：「**老師請讓我合格，否則我找工作的時候會有困難。**」
- ⚠️ 層級關係：**Appeal to Pity ⊂ Appeal to Emotion**（憐憫係情感嘅一種，唔係反過嚟）

## 5. 言辭空廢 Empty Verbalism ⭐⭐⭐

**定義：以重言命題 (tautological proposition) 冒充事實陳述 (factual statement)，就構成空廢命題。**
- 分為：**絕對空廢**、**相對空廢**

### 5.1 絕對空廢 ⭐⭐
- **兩個條件：① 重言命題 + ② 冒充事實陳述**
  1. 因語句嘅**重言句形式**令語句**必然為真**，所以分辨空廢命題**唔係靠語句嘅真假**，而係靠上面**兩個條件**；
  2. **重言句本身缺乏信息內容，但不能視之為一種弊病**；但當重言句**冒充事實陳述**時，就成咗空廢命題。
- 例：
  - 記者：「做生意可以不管商業道德的嗎？」商人：「**做生意就是做生意。**」
  - 「你聽日嚟唔嚟參加活動？」「**會嚟的話就自然會來。**」
  - 「點解你咁鍾意瞓覺？」「**鍾意就係鍾意。**」
  - 記者問：「明年會出現赤字嗎？」財政司：「**若果明年總支出大於總收入的話，就會出現財政赤字。**」（財赤嘅定義本身，冇提供任何預測資訊）

### 5.2 相對空廢 ⭐⭐
1. 係**對空廢命題定義放寬後的產物**，令言辭空廢呢個**批判工具的可用性提高**；
2. **不要求語句具有重言句形式**，只要求**經分析語句內容及了解相關語境**，發現語句係以**必然為真的內容來冒充事實陳述**。
- 例：
  - 算命師：「**父在母先亡。**」（「父在，母先亡」或「父喺母之前亡」→ 點都中）
  - 算命師：「**你明年會有感情問題，事業會不順利。**」（含混到幾乎必中）
  - 國師：「**假如你發動戰爭，將摧毀一個強大的國家。**」（摧毀敵國定自己國家都「應驗」——古希臘 Delphi 神諭俾 Croesus 王嘅經典例子）
  - 數據分析員：「**明年市場會出現動盪。**」

### 5.3 絕對 vs 相對空廢（必考分辨）⭐⭐
| | 絕對空廢 | 相對空廢 |
|---|---|---|
| 句子形式 | **有**重言句形式（A 就是 A；如果 P 則 P） | **唔需要**重言句形式 |
| 點樣發現 | 睇**形式**就知必然為真 | 要**分析內容 + 了解語境** |
| 例 | 「做生意就是做生意」「鍾意就係鍾意」 | 「父在母先亡」「明年市場會動盪」 |
| 共通點 | 都係以**必然為真的內容**冒充**事實陳述** → 冇提供任何關於世界嘅資訊 |

## 5½. 課堂補充：講者點考（以此為準）⭐⭐⭐

- ⭐ **謬誤名稱唔使背、唔使寫**——知道「**邊個謬誤對應邊個語言特質**」就得：字詞歧義 → Equivocation；語句歧義 → Amphiboly；含混 → Continuum / Slippery slope；著色 → Appeal to emotion（pity）。
- ⭐ **歧義、含混大約得四五題 MC（頂多）**；問「呢個字詞**有冇歧義**？」→ 答「**有**」（基本上所有嘢都有歧義）；**唔會問有幾多種歧義**；**語音歧義唔考**（冇錄音機）。
- ⭐⭐ **「小時偷針，大時偷金」唔係滑坡謬誤**，係**錯誤類比**：滑坡要有**環環相扣、至少 A → B → C 嘅因果推論鏈**，由「可能」講成「必然」；單純類比冇推論鏈。
- ⭐ 滑坡：**有可能嘅發展 ≠ 必然嘅結論**（主動安樂死 → 被動安樂死係可能發展，但未必去到草菅人命）。
- ⭐ 含混：**冇明確界線 ≠ 冇界線**（有約略界線）；連續體謬誤＝將「冇明顯界線」推到「冇界線」（講者例：同朋友「每份功課差兩三分」，加埋差 20 幾分）。
- ⭐ **一個字詞可以同時有歧義、含混、著色**（「67」、「成功」：成功＝生存？／KPI 幾多先算？／正面著色）；含混字詞經釐清可能發現仲有歧義（「高」：形容詞 vs 姓高；CGA 高唔高）。
- 「**邊個都睇唔上**」：除咗語句歧義，仲牽涉字詞歧義（「上」）。歧義好處：減低造字成本、語言避諱（「我朋友走咗」）、文學創作、避重就輕。
- ⭐ 著色字詞：情緒意義**隨年代改變**——「公僕」（舊時負面 → 而家反而講謙卑）、「公務員」（中性？）、「**鬼佬**」（講者認為而家已冇負面）；「還有／剩下半杯水」。**事實改變唔到**：要說服人就要**建基於事實**，唔好靠著色字詞；文學唔應避著色字詞；講者：人文學科入面真正可以避開著色字詞嘅係**歷史**。
- 有冇冒犯（「你都幾堅定」）由邊個判斷——評價性，「有事實基礎，但冇事實嘅答案」；**MC 唔會問**。
- ⭐ **訴諸憐憫**：所講嘅可以係**事實**（佢真係孤兒；真係會難搵工），但**唔係相干嘅理由**。
- ⭐⭐ **言辭空廢嘅問題唔係假**——重言句**必然真**；問題係**冒充事實陳述**（「你最差嘅地方唔係講錯嘢，而係冇講過嘢」）。絕對空廢嘅形式：「**A 就是 A**」、「**因為 A 所以 A**」、或者**畀你一個定義**（財政司財赤）；**相對空廢**要分析內容＋語境，而且**可以由歧義導致**（父在母先亡）。「有信息內容但你覺得冇養分」（評價）≠ 冇信息內容（空廢）。
- ⭐ **謬誤未必係假**（Module 6：有啲謬誤甚至必然真）——謬誤係錯誤、混亂嘅思維。

## 6. 考試速攻 ⚠️⭐

| 講法 | 答案 |
|---|---|
| 講者嘅語言陷阱包括歧義、含混、著色字詞、言辭空廢 | **T** |
| 字詞歧義導致 Fallacy of Amphiboly | **F**（字詞 → **Equivocation**；語句 → **Amphiboly**） |
| 「路不通行不得在此小便」係語句歧義 | **T** |
| 「欠」「發夢」「掛號」係字詞歧義 | **T** |
| 歧義一定有問題 | **F**（不一定，可以係必需：免增新詞、避諱、創作、避重就輕） |
| 「因荷而得藕，有杏不須梅」係利用歧義創作 | **T** |
| 「下雨天留客天留我不留」係避重就輕嘅例子 | **T** |
| 「有室友勝過沒有任何東西…」係 Equivocation | **T** |
| 「我們不應該支持他，他是反對美國的單邊主義提倡者」係 Equivocation | **F**（係 **Amphiboly**） |
| 含混語辭係語言中不能或缺嘅 | **T** |
| 制定法例時應避免歧義同含混 | **T** |
| 連續體謬誤：利用含混，將能約略區分嘅事物視為不能區分 | **T** |
| 「我和拿 A- 的室友差不多」係 Slippery Slope | **F**（係 **Continuum Fallacy**） |
| 滑坡謬誤每一環節嘅因果關係都係必然 | **F**（只係**可能**，唔係必然） |
| 「上莊 → 冇時間讀書 → 成績差 → 搵唔到工」係 Slippery Slope | **T** |
| 著色字詞嘅情緒意義或會隨時間改變（如「鬼佬」） | **T** |
| 「參考／抄襲」形容相同狀況但情感唔同 | **T** |
| 訴諸情感係訴諸憐憫嘅子類 | **F**（**反轉**：憐憫係情感嘅子類） |
| 殺父母嘅人以孤兒身份求情係 Appeal to Pity | **T** |
| 言辭空廢 = 以重言命題冒充事實陳述 | **T** |
| 分辨絕對空廢靠語句嘅真假 | **F**（靠**兩個條件**：重言命題 + 冒充事實陳述；佢**必然為真**） |
| 重言句本身就係一種弊病 | **F**（缺乏信息內容但**唔係弊病**；**冒充**事實陳述先係問題） |
| 相對空廢要求語句有重言句形式 | **F**（唔要求；分析內容 + 語境） |
| 「若果明年總支出大於總收入就會出現財赤」係絕對空廢 | **T** |
| 「父在母先亡」係相對空廢 | **T** |
| 相對空廢令言辭空廢呢個批判工具嘅可用性提高 | **T** |
| 「小時偷針，大時偷金」係滑坡謬誤 | **F**（係**錯誤類比**；滑坡要有 A → B → C 環環相扣嘅因果推論鏈） |
| 言辭空廢嘅問題在於佢講嘅嘢係假 | **F**（重言句**必然真**；問題係**冒充事實陳述**、冇講過嘢） |
| 一個字詞可以同時有歧義、含混同著色 | **T**（例：「成功」「67」） |
| 謬誤嘅結論一定係假 | **F**（謬誤係錯誤混亂嘅思維，**未必係假**） |
