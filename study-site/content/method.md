# 點樣用最少時間攞最高分？（有研究根據）

> **結論先講**：唔好淨係「睇」筆記。**做題 → 對答案睇解釋 → 錯題隔一陣再做**，係研究證實最有效嘅方法。呢個網站成個設計都係圍繞呢點。

## 1. 研究講咩？

| 方法 | 研究結果 | 呢個網站點用 |
|---|---|---|
| **Practice testing / Retrieval practice（做題、主動回憶）** | Dunlosky et al. (2013) 評估 10 種常用溫書方法，只有**兩種**評為「**high utility**」：practice testing 同 distributed practice。Rowland (2014) meta-analysis：做測驗比重讀效果大（g ≈ 0.50）；**有 feedback** 時效果更大（g ≈ 0.73 vs 0.39）。 | ✍️ 練習：每題即時對答案 + 解釋 |
| **同真考試格式一致** | Adesope et al. (2017)：practice test 整體 g ≈ 0.61；練習題型同真考試題型**一致**時效果更好；MC 練習效果好（g ≈ 0.70）。 | 題庫全部係 **MC + T/F**（同 midterm 一樣）；⏱️ 模擬考計時 50 分鐘 |
| **Distributed / spaced practice（間隔重溫）** | Dunlosky 評為 high utility：同一份嘢分開幾次溫，好過一次過。 | 答錯嘅題目會喺**幾題之後自動再出現**；錯題本要**連續答啱兩次**先算掌握 |
| **Interleaving（混合練習）** | Dunlosky 評為 moderate：混合唔同類型嘅題目，訓練你**分辨**相似概念。 | 智能練習會**混合課題**；🔀 易混淆頁專攻 歧義/含混、檢證/印證…… |
| **Elaboration / self-explanation（解釋點解）** | Dunlosky 評為 moderate。 | 每題都有「💡 點解」；筆記有 ⚠️ 陷阱提示 |
| **Rereading / highlighting / summarizing（重讀、間螢光筆）** | Dunlosky 評為 **low utility**。 | 筆記已經幫你濃縮好；**唔好花時間抄筆記** |
| **Pretesting（未讀先考）** | 先嘗試答（就算答錯）會令之後學得更牢。 | 🎯 一開始先做診斷測驗 |
| **Sleep（瞓覺）** | 學完之後瞓一晚，記憶保留明顯較好（例：一項 52 人研究，sleep 組保留顯著較多，d ≈ 0.72）。 | 計劃明確叫你**瞓覺**；通頂會蝕底 |

## 2. 今晚 + 明早嘅衝刺計劃（首頁可以逐項剔）

**今晚（約 3–4 個鐘，之後一定要瞓）**
1. 🎯 **診斷測驗**（10 分鐘）：未溫都做，估錯都有用。
2. ⚡ **速記表** + 🔀 **易混淆**（20 分鐘）：先搭好成科嘅框架。
3. 📚 **Module 2 逐章**（60 分鐘）：每章睇「0. 一頁總覽／一句總結」→ 撳「測試呢章」→ 睇錯題解釋 → 先至返去睇筆記入面你唔識嘅部分。
4. 📚 **Module 3 逐章**（50 分鐘）：同上。
5. 🎙️ **課堂補充**（10 分鐘）：講者喺堂上講過嘅考試提示同例子。
6. ⏱️ **模擬考**（45 分鐘）：40 題、50 分鐘，當真咁做。
7. ❌ **錯題本**（20 分鐘）：重做到全部清晒。
8. 😴 **瞓覺**。

**明早（考試前 30–45 分鐘）**
1. 🃏 **閃卡**（只溫「未熟」）
2. ❌ 錯題本最後一 round；⚡ 速記表掃一次
3. 🎒 帶 **Student ID、鉛筆、擦膠**；LT-B，**09:30 開考，09:45 後唔准入場**

## 3. 考場答題技巧（MC + T/F）

- ⭐ **答錯唔扣分**（講者堂上講：「答對有分，答錯冇分」）→ **每一題都要答，唔好留白**。
- ⭐ **題型同分數**：少過 50 題、50 分鐘（每題平均 ≥ 1 分鐘）；三種題型：**T/F**、**問題分類（概念/事實/評價 三選一）**、**ABCD 四選一**（冇 ABCDE）。**T/F 每題分數比多選項 MC 少** → T/F 快手做，**留多啲時間畀 ABCD 題**。
- ⭐ **問題分類題**：一條問題只屬一類；先試概念（淨係分析字義答唔答到？）→ 再試事實（原則上用經驗方法答唔答到？）→ 先至評價；**數學一律係概念**；「某人點樣講／點樣 define X」係**事實**。
- ⭐ **睇清楚句號定問號**：「4 + 5 = 8。」（陳述句）係錯；「4 + 5 = 8？」係一條**概念問題**（問題本身冇錯）。
- **T/F 陷阱字眼**：「**一定**」「**永遠**」「**唯一**」「**所有**」「**完全**」「**只要…就**」——課程好多重點都係「**不一定**」（例：歧義不一定有問題；含混不一定是缺憾；闕義不一定有害；冇認知意義不一定冇意義）。
- **方向反轉題**：好多 T/F 會將關係倒轉：實化（非具體 → 具體）、Appeal to Pity ⊂ Appeal to Emotion、內涵決定外延（唔係反過嚟）、通得過檢證 ⇒ 通得過印證（唔係反過嚟）。
- **分類題**：先搵**關鍵字** → 對應概念（例：「應該／美／正確」→ 評價問題；「就是…就是」→ 絕對空廢；「每一步可能導致」→ 滑坡）。
- **英文題**（Copi reading 部分可能用英文出）：genuine / merely verbal / apparently verbal but really genuine；belief vs attitude。
- **事實問題冇講年份**：講者喺堂上提過，考卷上冇標年份嘅事實問題，理解為**考試當日（現在）**嘅事實。
- 時間：50 分鐘，唔肯定就先估一個答案、用標記遲啲返嚟睇——**唔好留白**。

## 4. 網站使用貼士

- 進度自動儲存喺呢部機（localStorage），換機或者清 browser data 會冇咗。
- 鍵盤：**1–4 / A–D** 揀答案、**T / F** 判斷題、**Enter** 下一題；閃卡 **Space** 揭卡、**1/2/3** 評分。
- 筆記章尾「考試速攻」表嘅答案會**模糊化**，撳一下先睇——逼自己先諗。
- 右上角 **A− / A+** 調字體大小，**🌓** 切換深色模式。
- 呢個係一個獨立 HTML 檔案，可以 send 去手機用（WhatsApp / AirDrop / email 俾自己），喺手機 browser 開就得。
