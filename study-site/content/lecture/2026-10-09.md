  - 🔗（筆記對照，唔係講者原話）slides 原則：「內涵固定則外延固定」。講者呢度講嘅「外延改變」係指修正咗過往嘅判斷錯誤；考試問嗰條原則就跟 slides 答。
- 預告 Module 6：人最大嘅問題唔係錯，係**雙重標準**；最嚴重嘅 double standard 係「**搬龍門**」——把尺今日同昨日唔同，所以永遠唔會錯。（[01:38]–[02:41]）
- ⭐ **理想伴侶**：你有一張擇偶條件（同自己性別唔同、年齡差距 ±3 歲、咩 major、CGA……）= **內涵**；**條件越多，通常選擇越少**——「但去到某個位可以是一樣的」：例如其中一個條件係對方財產要多過 Elon Musk（錄音作「EI Mass」），咁再加不合理條件都唔再影響你嘅擇偶 pool（本來世界上就冇呢樣嘢；錄音略不清）；不過講「人」係包括未來，「永遠有機會有人有錢過 Elon Musk」——你仍然可以有呢個內涵要求。（[05:34]–[07:19]）
  - 🔗（筆記對照）= slides「內涵遞增，外延**不遞增**（可以保持不變）」。

- 感情關係：咁樣搵伴侶，除非內涵要求好低，否則符合條件嘅對象好少；「沉船」= 思考斷線，冇批判思考；timing 好重要，批判思考幫唔到你；「對的人」個「對」字好含混。每次 execute 批判思考其實係限制緊自己發展關係；就算李天命話要將批判思考放入日常生活，**都係睇 context**——要好認真思考就用，處理人際、感情、家庭關係唔一定下下咁用。（[08:51]–[11:29]）

### ⭐ 定義練習（Mentimeter／sample questions）

- ⭐⭐ 「**正方形為四條邊的圖形**」→ **太闊**：判斷太闊 = 會包咗唔應該係正方形嘅嘢入去，例如**長方形**。（[12:10]–[12:59]）
- ⭐ 「**家屬**指的是父母、兄弟」（題目原文錄音不清）→ 家屬仲有兄弟姊妹、祖父母，「你講多兩個都得」；「阿爺阿嫲（錄音作「阿爺阿媽」）唔算家屬呀？**排除咗佢哋在外**」→ 即**太窄**（錄音作「太雜」，按上文應為「太窄」）；帶男／女朋友見家長都要小心有冇排斥咗佢做家屬。（[12:59]–[14:40]）
- ⭐ 但如果改做「家屬指的是父母兄弟姊妹**等等**」或者「家屬指的是**例如**父母兄弟」→ 係**舉例說明（非完整外延）**——「講唔晒㗎嘛」，可以係合理定義。（[14:40]–[15:17]）
- ⭐ 「**人是理性的動物**」（太闊／太窄／循環／合理定義？）——講者：「**沒有準確答案**」；佢教咗幾年，今年係第一年全班傾向答「合理定義」（2020 年疫情時得約 60 人，「被西方哲學家荼毒」，覺得「人唔係理性㗎咩」）。（[16:48]–[17:53]）
  - **唔係循環**：循環即係「人」= 「理性」，兩個概念可以互換——但 AI 都係理性，互換就變成「AI 是人」。（[17:53]–[19:27]）
  - ⭐ 判斷合唔合理，其實返去 Module 2 問題分類嘅概念問題「**理性是什麼？**」——用定義方法諗「理性」嘅內涵：會唔會包括唔應該包括嘅嘢（太闊）、會唔會排斥應該係人嘅嘢（太窄）。（[19:27]–[20:28]）
  - 太闊：如果以「能夠使用工具」等智能做理性內容，外延就包括某啲智能相對高嘅物種。（[20:28]–[21:09]）
  - ⭐ 太窄：**排斥咗嬰兒**（「我通常舉例」）——生物學上 BB 仔係人類嘅幼年期 = 人；如果你將「理性」理解為要為自己行為負責（牽涉社會政策討論，好似 18 歲成年嘅標準），就可以將 BB 仔排斥喺你嘅「人」概念之外 → 兩種「人」嘅理解唔同，透過定義釐清大家對「人」嘅了解唔一樣。（[21:09]–[24:23]）
- 「人是理性的動物」同「獨角獸」都係西方哲學常用（但好舊）嘅例子。（[24:23]）
- ⭐ 「**心理學是研究心理相關的學科**」→ **循環**：你冇讀過心理學，問一個讀緊 UST psychology course 嘅朋友，佢咁答你——第一印象係「空廢」、**冇訊息內容**、冇講過嘢畀你聽；對比「研究人類和動物的心理現象、意識和外在行為的科學」——起碼提供咗訊息內容（人、動物、心理現象、外在行為；「科學」亦係一個 concept）→ 唔循環。（[25:21]–[26:28]）
- ⭐ 「**獨角獸是頭上有一隻長角、有馬的身體的動物**」（講者：「這個應該都沒有絕對的了」）：（[24:23]–[32:42]）
  - 揀「循環」：講者認為**唔合理**——「獨角」有冇 locate 到喺身體邊個部分？冇；「獸」一定係馬？唔一定 → 成個界定端有提供訊息內容。（[26:28]–[27:37]）
  - 揀「**合理定義**」：可以——講明係**西方神話既有嘅形象**，跟返嗰個定義；溝通時先講清楚「我講嘅獨角獸係西方神話入面嗰個形象」，「你咁 present 出嚟就冇錯」（講者提到合理定義嘅原因同某種已定嘅屬性有關；錄音不清）。（[27:06]–[29:12]）
  - 呢個定義亦「頗有歧視成分」：角要長、要馬嘅身體——驢仔（錄音作「雷仔」）同駱駝都唔得。（[27:37]–[28:07]）
  - 對方話**太闊**：包咗犀牛（錄音作「西牛」）？——「長」係**含混**嘅。（[29:12]–[29:53]）
  - 對方話**太窄**：現代生物學角度任何有單一隻角嘅動物（有同學舉獨角嘅魚；錄音不清）；高達 fans：「獨角獸」係一部高達；讀 Econ：「獨角獸」係市值去到某個位嘅公司。（[29:53]–[32:02]）
  - ⭐ 結論：透過內涵外延嘅關係，可以釐清大家係咪企喺同一個平台——大家講嗰樣嘢時**外延唔一樣，就反推內涵會唔一樣**；**定義嘅價值主要係釐清歧義**：究竟大家講緊乜嘢獨角獸、對「人」嘅定義係咪相同。（[31:29]–[32:42]）
- 釐清 = 先企喺同一個平台（問題分類嘅平台：概念／事實／評價）；分析哲學傳統只可以**嘗試**透過呢個功夫釐清，「但實質上未必成功」→ 所以後來發展到符號邏輯，將所有嘢符號化（講 X、講 Y，先問 X 係咪等於 Y）。（[32:42]–[33:42]）

- 「**甚麼是色情電影？**」——用內涵外延嘅提問了解概念：「有裸露鏡頭」？我拍一套拳擊電影，兩個競技者赤裸上身喺擂台肉搏——暴力，唔色情；「赤裸嘅性行為」？著衫算唔算？再釐清做「性行為 = 色情」→ Discovery Channel 好多嘢都變咗色情。（[34:14]–[35:33]）

### ⭐ 一個概念冇外延，係咪代表冇意義？

- 「意義」呢個字本身係**歧義**嘅：要問係咩層面有意義；籠統講，只要喺某一個層面有意義就叫有意義——例如講創新嗰本書（藍色 mind map），冇外延嘅概念有**創新意義**。（[39:21]–[41:10]）
- ⭐ 冇外延 = 現實世界搵唔到嗰樣嘢；傳統邏輯書用**獨角獸**：虛構生物、冇外延，但個概念**有意義**——喺分析哲學，有意義代表有真假、畀我哋一種知識。（[41:10]–[42:12]）
- ⭐ 例子：男／女朋友生日要一隻獨角獸公仔——你起碼識買隻有角嘅犀牛公仔，唔會買河馬（買河馬就出事）；現實世界冇獨角獸，但獨角獸作為一種知識、一個**純粹嘅內涵**，令我哋了解獨角獸講緊乜，同時知道**咩唔係獨角獸**。（[42:12]–[43:19]）

### ⭐ 認知意義：有冇真值

- 分析哲學家：先有概念（知識），再判斷外在事物同腦入面概念嘅契合度（火星上見到一個似男性嘅嘢；收到一件禮物係咪獨角獸形狀）；佢哋用呢套判斷唔同範疇嘅知識有冇價值——「這是一個價值系統，最後是主觀性」：呢班哲學家判斷其他學科係咪喺度探求真理，定係喺度「吹水」；佢哋把尺叫 **Cognitive Meaning（認知意義）**。（[43:19]–[45:43]）
- ⭐ 「認知意義」喺其他 critical thinking 範疇都常用，但**分析哲學用嘅定義窄好多**：判斷一個說法有冇**真值 (truth value)**——即係有冇真假可言。（[45:43]–[46:44]）
- ⭐⭐ **「真值」有歧義**：日常講「真」就排除咗假；但作為學術用語，truth value 包含**真、假兩個值**——**一句假嘅說法都有真值**。（[46:44]–[47:49]）
- 例子：（[47:11]–[51:09]）
  - 「香港科技大學位處香港西貢區」→ 真，有真值。（[47:11]）
  - ⭐ 「史維是香港科技大學現任校長」→ **假——「假的都有真值」**（好似正負數：真嘅 truth value 係真，假嘅 truth value 係假）。（[47:11]–[48:30]）
  - 「史維是香港科技大學校長」（冇講「現任」）→ 講者：上個 topic 講外延包括過去、現在、未來，**冇特別釐清就用返佢哋嘅框架——真**；日常討論你可以先釐清「你係咪問現任？」。（[48:30]–[49:10]）
    - 🔗（筆記對照，唔係講者原話）筆記版 slides 將呢句標為「有真假，但時間闕義」；09-14 講者亦講過「事實問題冇標時間 = 而家」。考試最穩陣嘅考點係：**呢句有真值**。
  - ⭐ 「史維是香港科技大學前任校長**嗎？**」→ **冇真假可言**：問題本身唔係知識，而係要求一個知識（好似參觀嘅小學生問「哥哥姐姐……」）；**答案先有真假**——你答「史維係邊個？冇聽過，所以佢唔係」→ 你個答案係假。（[49:10]–[51:09]）
- ⭐ 頭三句係**述句**：嘗試對世界有個描述、論斷——提供一種知識，有真假可言。（[49:10]–[50:00]）
- ⭐ 意義判準之下：**一個說法需要談得上真假，先有認知意義**。（[51:09]–[51:41]）

### ⭐ 分析述句 vs 綜合述句

- ⭐ 有認知意義有兩個可能：① 透過**語句分析**檢測到真假 → 相對於**概念問題** → 歸類為**分析述句**；② 透過**經驗方法** → 相對於**事實問題** → **綜合述句**。Module 2 係由問題嘅角度講，呢個 topic 係由答案／知識層面講。（[51:41]–[52:47]）
- ⭐ 分析述句主要三類，第一類**恆真句 (tautology)**：必然地真。「外面有下雨或者沒有下雨」——你唔使郁、唔使出去睇；「外面有下雨」先要經驗方法（行出門口睇）。（[52:47]–[56:23]）
- ⭐⭐ **問「外面有沒有下雨？」→ 答「外面有下雨或者沒有下雨」= 絕對空廢**：懶得出去又唔想講錯，就講啲冇信息內容、必然真嘅嘢；我唔可以話你錯；**你個答案有認知意義**（有真假可言、係真）——空廢係你犯咗嘅「另一個毛病」，但純粹喺意義判準角度，你呢句係真。（[56:23]–[58:16]）
- 諗下呢句喺咩情況下係假？舉唔到例——「你要定義一件事定義不到就舉例；你舉不到例，有沒有問過自己為何舉不到例」；好似「親生父母年紀一定比你大」，了解字詞就知答案；「外面有下雨或者沒有下雨」甚至唔使知咩叫外面、咩叫落雨，只要知「有」係「冇」嘅相反、同「或者」——透過語句形式就知必然真。（[58:16]–[61:04]）
- 「他是年輕人，則他不可能是老人」：你可以話佢肉體年輕、心境老——釐清後（都講生理、生命周期）兩者唔可以同時發生 → 必然真。⭐ **必然真嘅嘢係有認知意義嘅**。（[61:04]–[62:16]）（⚠️ 10-12 講者承認呢個例子唔好，見 10-12）
- **矛盾句**：「外面有下雨同時沒有下雨」「他同時是年輕人又是老人」→ 冇可能發生，**必然假**。恆真句論斷兩個情況、包括所有情況、二取其一 → 必然真；矛盾句論斷兩個冇可能同時發生嘅事。（[62:16]–[63:36]）
- ⭐ 第三類「**語義界定**」——「爭議大一點」（返去呢個 course 第一個爭議：白雪公主可唔可以係男人）：Module 4–5 符號邏輯完全冇呢個問題（唔牽涉具體內容，只睇語句／推論形式）；但要將分析哲學用喺日常語言，就容許透過語義（字典、數學 theorem by definition）判斷真假——問題係我哋會忘記或者懶得搵返點解王老五係未婚漢。（[63:36]–[65:18]）
  - **王老五是未婚漢**（bachelor = 未結婚嘅男性，英文字典定義）→ 真；**神奇女俠是男性** → 假（美漫形象係女性；男嘅你叫「神奇男俠」，冇理由用人哋個名）；**白雪公主是女的** → 真、「白雪公主是男的」→ 假——公主查字典係女性，王子係男性。（[65:18]–[66:40]）
- ⭐ **水的化學式**：喺分析哲學框架屬**綜合述句**，問「水的化學公式是什麼」係**事實問題**（考試會避）；唯一例外：將 H₂O 當成約定俗成、大家唔會改嘅定義（語意界定角度）→ 可以係分析述句／概念問題；但傳統上佢哋堅持係綜合——「即係你背咗答案」。（[66:40]–[67:50]）
- ⭐ **綜合述句**（要經驗事實分辨真假）：（[67:50]–[72:59]）
  - 「**地球上有生命**」（綜合真句）：唔係必然——上帝全善唔會咁做，但人類有可能令地球冇生命（某啲領導人玩核戰，蟑螂都冇埋）；機會率幾高都好，都要經驗事實支持——最簡單：舉手話「我係一個生命，我企喺地球」。（[67:50]–[70:30]）
  - 「**HUMA 1710 is a H-CC**」（綜合真句）：佢「而家」係 H-CC、唔係 S-CC；講者做 TA 嗰陣仲未有 common core；之後會唔會係，唔知——同「地球上有生命」比，改變嘅落差易好多（課程由 Common Core Director 自己教）。（[69:54]–[71:07]）
  - 「**地球是平的**」（綜合假句）：有冇可能係真？「你真係低估人類嘅破壞力」——用晒地球上所有炸藥炸到佢平為止。（[71:07]–[72:26]）
  - 「**HUMA 1710 is an A-CC**」（綜合假句）：好多人俾 course title 個「Art」誤導——「你 art 錯，thinking 都唔 art」。（[72:26]–[72:59]）
  - 「假嘅可唔可以變真？」留待下堂；概念上分析同綜合有三個唔同嘅地方（下堂講）。（[72:59]）

## 重點澄清

- ⭐ **分析哲學家睇世界：先有內涵（概念、知識），再睇世界有冇（外延）**——呢個係嘗試向科學靠攏。（[00:06]–[02:41]）
- ⭐ 定義重溫：**規創**（創新）→ 冇真假，淨係得接唔接受；**釐定** → 同含混字眼相關，冇真假，睇恰唔恰當；**字詞定義** → 消除歧義，**有真假可言**。（[02:41]–[03:47]）
- ⭐⭐ **字詞定義嘅「真」= 認知意義之下嘅真 = 唔太闊、唔太窄**，啱啱好包含到所有佢應該描述嘅事物。（[03:47]–[04:18]）
- ⭐ 太闊 = 包咗唔應該包嘅嘢入去；太窄 = 排斥咗應該包嘅嘢。（[12:59]、[20:28]）
- ⭐ 判斷循環：睇界定端有冇提供訊息內容——「心理學是研究心理相關的學科」冇；「獨角獸……」有。（[25:21]–[27:37]）
- ⭐ 外延唔同 → 反推內涵唔同；定義嘅價值主要係釐清歧義、令大家企喺同一個平台——但未必成功。（[31:29]–[33:16]）
- ⭐ 定義幫到我哋討論（色情電影、人生苦樂），但釐清之後，「某套係咪色情電影」「人生係苦定樂」最後仍然係主觀判斷。（[33:42]–[39:21]）
- ⭐ 冇外延 ≠ 冇意義（獨角獸）；「意義」本身有歧義。（[39:21]–[43:19]）
- ⭐⭐ 真值包括真同假；問句冇真值、答案先有；**談得上真假先有認知意義**。（[46:44]–[51:41]）
- ⭐ 恆真句 vs 重言句：講者自己將**重言句**淨係用嚟講「A 就是 A」（字面重複）；兩者有重疊（都必然真），但重言句未必包括「外面有下雨或者沒有下雨」；唔同書有唔同講法。（[52:47]–[54:42]）
- ⭐ **概念先於事實**：純粹語句分析時，未需要接觸世界發生咩事。（[54:42]–[55:16]）
- ⭐⭐ **空廢 ≠ 冇認知意義**：絕對空廢嘅答案係必然真、有認知意義；空廢係另一個毛病。（[57:38]–[58:16]）
- ⭐ 恆真句、矛盾句靠**語句形式**判斷；語義界定係為咗將分析哲學用落日常語言而容許，**爭議較大**。（[63:36]–[64:44]）
- 犯錯冇問題、要認；最嚴重嘅雙重標準係搬龍門（Module 6 再講）。（[01:38]–[02:07]）
