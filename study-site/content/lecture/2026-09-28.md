## 考試提示

- ⭐⭐⭐ **歧義、含混「冇乜好考」**：「呢度唔需要太擔心……歧義、含混呢啲考試，我諗係**四五題 MC 就完**——四五題頂多，四五題可能仲少」；叫大家代入出題者嘅角度諗。（[06:39]）
- ⭐⭐⭐ **問「有冇歧義」→ 答「有」**：「如果問你一個字詞有冇歧義性，你幾大都答**有**」——要解釋「冇歧義」成本非常高：就算佢搵十個 AI model 證明過冇歧義，你對卷時話「我有一個（意思）」，佢就要承認錯誤；所以佢「冇理由」出一條歧義題而答案竟然係冇歧義。（[06:39]–[07:39]）
- ⭐⭐ **含混同理**：「你只要講得出嗰樣嘢嘅含混性，你就唔使理其他人嘅解釋」。（[07:39]）
- ⭐⭐ **唔會問有幾多種歧義**：例如「67」嘅歧義，你只需要講出佢**係一個數字，同時係 Gen Alpha 嘅用語**（同香港粗口相近嗰啲唔使知）；「我絕對唔會問你某個字詞有幾多種歧義」——唔會有「A 4 種、B 5 種、C 6 種、D 7 種」咁嘅題目。（[08:12]–[08:41]）
- ⭐ **唔係語法課**：「我哋呢個課程首先唔係一個語法學嘅課程」；講歧義、含混，係睇一個講法、某啲論述會唔會導致超過一種意思。（[06:11]、[08:41]）
- ⭐⭐⭐ **「小時偷針，大時偷金」唔係滑坡謬誤**：「呢個考試如果我會問嘅話，你記得答案：小時偷針大時偷金**並唔係一個滑坡謬誤**」——係**錯誤類比**（Module 6 再講）。（[18:09]–[19:06]）

- 「我呢個課程係**唔會畀你定義乜嘢叫客觀**」。（[45:02]）
- ⭐⭐ **10 月 23 日考試**：「識就識，唔識就（揀；錄音作「擇識仔」）——**True or false、ABCD**」。（[59:24]）

## 課堂例子

### 歧義：「67」、紅磡站

- 有乜嘢冇歧義？基本上所有嘢都有歧義；**數學符號「勉強」可以叫做冇歧義**——但其他文化圈、唔同世代可能對某啲嘢有特別定義：L2 Mentimeter 問有乜字冇歧義，同學寫 1、2，有人寫「6、7」——67 係自然數（66 同 68 中間）；但亦係 **Gen Alpha 用語**（「你哋係 Gen Z，唔好扮後生」）；用廣東話讀要特別注意發音。（[00:40]–[02:27]）
- ⭐ 表弟妹話你「好 67」（錄音作「7-11」）代表乜？——**一個字詞可以具有歧義，同時有含混、有著色**；唔同世代有唔同用法，最好釐清佢 in what sense 用兩個數字形容你。（[02:27]–[03:16]）
- 講者親身經歷：大約十年前約一位 60 年代尾出世嘅師兄喺「紅磡地鐵站」B 出口等，等咗十分鐘都唔見人——講者喺紅磡站（東鐵綫），師兄喺**黃埔站**（觀塘綫，當時新開冇耐）：喺師兄眼中，紅磡區嘅地鐵站就係「紅磡地鐵站」，而講者去嗰個佢叫「**紅磡火車站**」。釐清其實講兩句好閒。（[03:16]–[06:11]）

### 含混（兼歧義）：「成功」「高」

- 大部分形容詞都含混：高矮、肥瘦、冷暖、**成功**（對失敗）；有冇約略嘅界線？有。但呢個界線究竟係去到歧義定含混，要釐清。（[09:16]–[09:47]）
- ⭐ 「**成功**」：評價一間大學成唔成功有唔同 ranking（QS、THE），但冇一個 KPI 係大學生自殺率；喺科大學生口中，「成功」被 create 咗「**成功 = 生存**」嘅意思，喺另一間院校教就冇呢個意思 → 經過釐清，可能發現佢**唔止含混，甚至有歧義**。（[09:47]–[10:52]）
- ⭐ 「**高**」：作為形容詞有含混性（幾高叫高）；亦有歧義（有人姓高）。講者讀大一時，問全班第一嘅內地同學（physics）CGA 高唔高，佢話「唔係太高」——當時科大 grade point 係 1–12（12 = A+、11 = A），11.5 係 round up 到 A+ 嘅門檻；對佢嚟講「**高低唔係形容詞，係階級**」（喺 A+ 入面唔算高）。講者：「how is it true or false，呢啲畀你哋參考」；「有錢」嘅 concept 喺社會上都係人人唔同。（[11:20]–[15:44]）
  - 後來再講：佢係咪「串」緊講者？佢只係**事實咁講一件事**——可以當事實問題查（嗰個學期幾多人 CGA 過咗某個 letter grade），亦可以概念分析（11.5 係門檻，所以一定唔高）；講者同兩個朋友三對一都覺得被串，唔代表就聽邊個判斷。（[43:24]–[45:02]）

### ⭐ Mentimeter：「小時偷針，大時偷金」係唔係滑坡？

- 滑坡謬誤（slide）：推論過程表現得環環相扣，實際問題係將每一層之間嘅意思**由一種可能性講到一種必然性**。（[16:57]）
- 「小時偷針，大時會唔會偷金？」——有可能，但證據不足；將 A 到 B 嘅可能性變成必然性；答「否」嘅同學可能已經睇咗 Module 6（會講多啲謬誤例子）。（[16:57]–[17:46]）
- ⭐⭐ 答案：**唔係滑坡謬誤**——邏輯家為咗本書寫多個例子，將滑坡謬誤同**錯誤類比**分開兩類：**錯誤類比** = 由一件事比較另一件事，當中有可能性但冇必然性；**滑坡謬誤** = 推論過程要係**環環相扣嘅因果關係**，「推論過程至少係由 A 到 B 到 C」——小時偷針呢度**冇推論過程**。錯誤類比都係謬誤，但唔歸類做滑坡，純粹係邏輯家喺謬誤分類上嘅唔同講法（Module 6 再講）。（[18:09]–[19:06]）

### ⭐ 著色字詞

- 著色字詞：用呢啲字時會**表達出情緒**。（[19:06]）
- ⭐ **堅定／固執**：形容同一種狀況（一個人不斷嘗試、堅持自己諗法、唔聽人講）——好聽啲叫堅定（有鼓勵性），唔好聽啲叫固執。（[19:56]–[20:28]）
- ⭐ **公僕／公務員**（情緒意義隨年代改變）：好舊時嘅香港，「公僕」係負面嘅（僕人）；慢慢演變成中性嘅「公務員」；而家「公務員」對你哋呢代係咪中性？（問有冇人覺得負面）；而家網上講「公僕」反而係講佢哋謙卑嘅特質——**同一個說法喺唔同年代可以由正面變中性、中性變負面、負面又變中性**。（[20:28]–[22:12]）
- ⭐ **鬼佬**：講者覺得而家冇人覺得「鬼佬」係負面字詞；「鬼佬」通常指白人（南亞裔另有稱呼）；講者喺紐約長大、教中學嘅表哥用嗰啲族裔稱呼係佢嘅常態，用得好中性——好似地盤佬用粗口做標點符號都好中性；唔係講佢文化水平高低（嗰個絕對係評價性），而係喺嗰個文化圈要 create 嗰種 language 先溝通到。（[22:12]–[24:26]）
- 同一個 context，唔同情感下用唔同字：**參考／抄襲**（「你哋通常唔會抄功課，只係參考」）；兩國打仗，自己一方傳媒話敵軍「**冷血殺人**」，對方傳媒將同一場景描述為「**英勇殺敵**」；半杯水心理學：「**還有**半杯水」定「**剩下**半杯水」。（[24:26]–[25:34]）
- ⭐ 好處：人係有情感嘅生物——但「**重點係我哋改變唔到事實**」：事實都係某國殺死另一國嘅人、你都係攞咗人哋嘢嚟抄、你都係好固執；事實可以好客觀咁描述。追男神／女神試咗十次都失敗——堅定定固執？唔知；但**事實上你就試咗十次，事實變唔到**。（[25:34]–[26:40]）
- ⭐ 做人需要心理調節（試咗十次都失敗，同自己講「我係一個好堅定嘅人」）；**壞處**：如果要透過論述 **convince 其他人**同意我哋，就應該**建基於事實，而唔係利用著色字詞**。（[26:40]–[27:46]）
- 日常最常見：**廣告用語**（唔講產品有咩特別，而係「唔買就笨」——錄音作「唔買就瘋」）；**政治宣傳**（講者唔講香港，講特朗普 Make America Great Again）。（[27:46]–[28:53]）

### ⭐ 李天命「地圖炮」：科學 vs 人文學科

- 李天命 reading：語詞可以盡量中性、不帶情感——科學／學術語詞大部分係**中性**（方程式、遞歸性、微系數；你覺得負面只係因為某科令你 suffer）；但去到社會、政治、倫理、文藝、宗教，寫文往往用帶情感意味嘅字（**階級、反動、壞蛋、神聖、叛教**）；嚴格學科有高度理論成就，人文學科遠遠落後、幾乎停滯不前；科學家冷靜客觀咁觀察、實驗、假設、演算，嗰班人就透過語言上嘅著色運用嘈交。（[29:26]–[33:25]）
- 講者評論：李天命避開社會科學，直接開火人文學科；有啲大學數學唔分入科學（科大就分）——⭐ **喺李天命系統，數學都唔算科學（Module 3 討論；錄音作「module field」），但對李天命嚟講係一個 positive comment**。（[30:59]–[32:55]）
- ⭐ 人文學科嘅人係咪真係可以避開著色字詞？講者：**著色字詞係人類語言必然嘅一部分**，人有需要——**情緒價值**（宗教某意義上都係）；講者建議唔好喺學術、課本搵情緒價值，喺家人、伴侶、朋友之間搵。（[33:25]–[36:10]）
- ⭐ **文學唔應該避著色字詞**——如果文學家都避咗著色字詞，就冇文學：DSE 嘅描寫文、抒情文寫唔到，淨返議論文；最後只可以做文學批評，而唔係創作。（[36:10]–[36:35]）
- 李天命一套除咗批判其他學科，亦用著色字詞批判當時其他哲學學派（英美分析哲學批評歐陸搞現象學嗰班）；喺哲學分類上亦唔應該講形上學；道德倫理要概念咁講——**道德只係人類嘅行為準則，冇其他內容**；分析哲學家盡量唔用著色字詞，後來發展到純粹邏輯。（[37:05]–[38:06]）
- ⭐ **歷史可以避開著色字詞**：「人文學科裏面真正做到嘅係歷史」——學術地描述一場戰爭：點解發生、過程、雙方死傷人數（數字表達），唔使講「英勇殺敵」、唔使加「正義／不正義嘅戰爭」。衍生問題：歷史學家係咪做緊科學研究？歷史系應唔應該畀 BSc 而唔係 BA？（文學畀 BA 好合理，BSc in Literature 就好矛盾）——**Module 3 返嚟再討論**。（[38:06]–[40:16]）

### 著色字詞：有冇冒犯，邊個判斷？

- 有人講「你呢個人都幾堅定」——有冇冒犯對方，由講嗰個、聽嗰個定第三方判斷？（MC 唔會問）同學答第三方 = **社會規範**；法律上被告某啲罪，用字點判斷——陪審團（社會遊戲規則）。（[40:48]–[46:45]）
- 但陪審員係咪就代表事實？講者：整件事係**評價性**——「**有事實基礎，但冇事實嘅答案**」；只可以基於講嘢嘅 context 分析，法律上規則就係第三方。提醒：講嘢小心，可免則免，唔好因為自己或身邊人覺得冇所謂就講。（[46:45]–[47:45]）

### 網上圖片真偽 & 分析標語字眼

- 網上見到嘅圖片要先懷疑真定假：有冇人去過現場？最好問當事人、問來源。⭐ 「**李天命教大家係訴諸事實**；但如果冇任何事實，只可以靠估，就要靠旁敲側擊嘅**佐證**」。（[47:45]–[51:30]）
- ⭐ 分析一句宣傳標語嘅字眼：有啲字冇著色、唔含混（例如地名）；「XX 的繁榮穩定」**含混**；「XX **成功**」係**著色**（positive，「千祈唔好話中性」）；而「**成功**」同時有**歧義**（成功執行咗？定係經濟發展／幸福指數嗰種成功？）同**含混**（唔同 KPI，要達到幾多先算）→ **一個字詞可以同時有著色、歧義、含混**。（[51:30]–[56:07]）
- ⭐ 小結：同前兩類語言特質一樣，**著色字詞喺人類語言入面係存在嘅；重點係要判斷佢有冇影響我哋嘅思考**。（[56:07]）

### ⭐ 訴諸情感 → 訴諸憐憫

- **訴諸情感**係一個謬誤大類，入面有一個子類叫**訴諸憐憫**：通常透過講話博取對方同情，而**避開事實嘅理據**。（[56:38]）
- ⭐ 有人殺咗自己父母（有證據，錄音提到指紋），向法官求情，理由係佢已經係孤兒——係事實，但**唔係求情理由**：孤兒狀況係你自己一手一腳造成。（講者補充：釐清「殺死咗佢**親生**父母」之後，「呢個人係咪孤兒」就變成概念問題。）（[57:08]–[57:40]）
- ⭐ 考試作弊被捉、唔合格，向老師求情：「請讓我合格，唔係我搵工好困難」——都係事實（HR 見到 transcript 連 HUMA1710 都 F），但唔係求情理由：作弊係你自己嘅自由選擇。（[57:40]–[59:24]）
- 講者自嘲：如果有人作弊，佢會上網話「一個人文學部教授技術能力低，揭發唔到學生作弊」——「你覺得我博唔博到大家同情？」（訴諸憐憫）；同情感著色字詞一樣要避免。（[60:30]–[61:32]）

### ⭐ 言辭空廢（Empty verbalism）

- 定義：**用重言命題冒充事實陳述**。正常嘅事實陳述：數據調查、去現場睇發生咩事、做實驗；但有一種「語言藝術」係用重言命題冒充事實陳述。分**絕對空廢**、**相對空廢**。（[61:32]–[62:36]）
- ⭐⭐ **絕對空廢**要跟言辭空廢成個定義，有**兩個條件**：① **重言命題**（係一個語句形式）；② **冒充事實陳述**。⭐ 言辭空廢嘅問題**唔係在於佢講嘅嘢係假**——重言命題係**必然真**嘅語句，只係透過講出必然真語句去**假裝講咗嘢**，係一種思考溝通上嘅毛病。（[62:36]–[63:05]）
- ⭐ 記者問商人：「做生意可唔可以唔理商業／社會嘅道德？」（[63:05]–[68:55]）
  - 受過批判思考訓練嘅商人應該**先釐清**：乜嘢係商業道德？道德只係一種行為規範——違反咗，證監會會搵我；我冇違反；你覺得唔道德係你嘅價值判斷。乜嘢係商業行為？低價買入、高價賣出係合理商業行為；高價買入、低價賣出都係（失敗嘅）商業行為——都牽涉交易、物品、貨幣。（[63:37]–[66:01]）
  - 呢個答法可能「好似冇乜養分」，但**有信息內容（information content）**——有冇養分係你嘅評價；定義可以再討論（BBA 同學可以 clarify、講 Adam Smith、畀第二個定義），可以溝通。（[66:01]–[68:17]）
  - ⭐ 但「**做生意就是做生意**」：**重言句形式「A 就是 A」——冇信息內容、冇講過嘢**，冇解釋過乜嘢係生意；呢個回覆**必然地真**。同類：「會來就是會來」「喜歡就是喜歡」「我就是我」「睡覺就是睡覺」。（[66:32]、[68:17]–[69:39]）
- ⭐⭐ 留意：言辭空廢有個條件係要**冒充事實陳述**——「你聽日會唔會嚟參加活動？」問嘅人期望你畀信息內容（嚟定唔嚟）；答「會來的話就自然會來」：**你最差嘅地方唔係講錯嘢，而係你冇講過嘢**——結果嚟唔嚟你都冇講大話，必然真，「你好保守」。（[69:39]–[70:16]）
- 「點解你咁鍾意瞓覺？」「鍾意就鍾意」——人哋可能想認識你；你可以答「唔係我鍾意瞓，係環境令我瞓」。（[70:16]–[70:51]）
- ⭐ 「明年會唔會出現財政赤字？」（問題分類時都提過）財政司答：「如果明年總支出大過總收入，就會出現財政赤字」——**未必係「A 就是 A」嘅感覺，而係畀你一個定義**。（[70:51]–[71:37]）
- ⭐⭐ **相對空廢**：言辭空廢定義**放寬**之後嘅產物，**加強佢嘅使用率**——唔再需要重言句形式，而係要求**分析語句內容、了解相關語境**之後，就知道結果必然真。（[71:37]）
- ⭐ 算命師（先講你知嘅嘢——父母現況——建立關係）：「**父在母先亡**」——⭐ **一個人嘅言辭空廢可以係因為歧義所導致**：「父在，母先亡」（爸爸健在、媽媽過咗身）或者「父喺母之前亡」；就算你話兩個同時離世，算命師都可以話「你爸爸好錫你媽媽，答應過唔會先走，捱住最後一啖氣睇住媽媽先走，遲幾秒先走」。呢個就係**相對空廢**——相對於絕對空廢，係「稍為鬆散嘅狀態」。（[74:00]–[76:34]）
- ⭐ 絕對 vs 相對：絕對要**重言形式**——「A 就是 A」、「因為 A 所以 A」，或者第三種情況「**畀你一個定義**」；相對要**分析當時嘅內容同語境**（算命師嘅語境：統計上好少兩個人同時離世）。（[75:36]–[76:05]）
- 算命師先講你知道嘅內容，講啱咗你先會再問感情問題——「我哋星期五再講感情問題」。（[76:34]）

## 重點澄清

- ⭐ **基本上所有嘢都有歧義**（包括語音、語境上嘅歧義）；數學符號勉強算冇歧義，但唔同文化圈、世代都可能有特別定義。（[00:40]–[01:31]）
- ⭐ 一個字詞可以**同時**有歧義、含混、著色。（[02:49]）
- ⭐ 呢個課程唔係語法學課程：重點係唔同人、唔同 channel 見到嘅嘢唔同，所以討論時最好先釐清。（[06:11]）
- ⭐ 含混字詞經釐清，可能發現**唔止含混，仲有歧義**（成功、高）——「界線究竟係去到歧義定含混，需要釐清」。（[09:47]–[11:20]）
- ⭐⭐ **錯誤類比 ≠ 滑坡**：slide 對滑坡嘅描述係「由可能講成必然」，但講者強調滑坡**要有環環相扣、至少 A → B → C 嘅因果推論鏈**；單純由一件事類比另一件事（小時偷針 → 大時偷金）係錯誤類比。（[16:57]–[19:06]）
- ⭐ 著色字詞：好處（人有情感、心理調節、文學創作）vs 壞處（說服他人時應建基於事實，唔應靠著色字詞）；**事實改變唔到**，可以客觀描述。（[25:34]–[27:46]、[36:10]）
- ⭐ 李天命：**數學唔算科學**（佢眼中係 positive comment）；歷史學可以避開著色字詞，但歷史研究算唔算科學 → Module 3。（[32:21]、[40:16]）
- ⭐ 有冇冒犯係評價性：**有事實基礎，但冇事實嘅答案**；講者唔會定義「客觀」。（[45:02]–[46:45]）
- ⭐ 李天命教**訴諸事實**；冇事實時只能靠佐證「估」。（[51:04]）
- ⭐ 訴諸憐憫 ⊂ 訴諸情感；所講嘅可以係事實，但唔係相干嘅理由。（[56:38]–[59:24]）
- ⭐⭐ 言辭空廢：問題唔係假（重言句**必然真**）；**冒充事實陳述**先係空廢；「有信息內容但你覺得冇養分」（評價）≠「冇信息內容」（空廢）。（[62:36]–[69:39]）
- ⭐ **歧義可以導致（相對）言辭空廢**（父在母先亡）。（[74:30]）
